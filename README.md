# 汽配批发管理系统

## 启动

1. 在 Windows 10/11 安装 Python 3.10 及以上，安装时勾选 Add python.exe to PATH（Python 3.11/3.12 也可以）。
2. 解压本目录，双击 `启动软件.bat`，或者在终端运行 `python app.py`。
3. 不需要安装 pip 第三方库，也不需要服务器或联网。

## 使用 uv 管理环境

项目使用 Python 3.12，仅依赖标准库。在已安装 uv 的电脑上，在项目目录执行：

```sh
uv sync --locked
uv run app.py
```

本机已创建 `.venv` 虚拟环境，也可以直接运行 `.venv/bin/python app.py`。
Windows 下对应命令为 `.venv\Scripts\python.exe app.py`。
虚拟环境不能跨系统复制，换到 Windows 后请重新执行 `uv sync --locked`。

## 第一次使用

1. “系统设置”：填写公司名、经营范围、公司地址、联系电话，点击“保存设置”。资料保存在数据库中，也会包含在数据库备份内。
2. “商品库存”：先新增商品（名称、单位、价格）。货号在保存时自动生成，如 `SP000001`，单位从“个、件”中选择，默认“件”。初始库存为 0；原有商品的货号和单位保留。
3. “采购入库”：选择商品，输入数量和进货单价，点击“确认入库”。每次入库一款商品。
4. “客户管理”：新增客户。
5. “销售开单”：选择客户，逐个添加商品到清单，填写本次收款，点击“确认销售出库”。自动扣库存并记录剩余欠款。
6. “客户欠款”：选择欠款单据，登记后续收款。
7. “销售记录”：查询历史销售单、打印或导出 CSV。

在“商品库存”点击“新增”保存商品。清单左侧可勾选多个商品，点击表头“全选”可全选或取消全选，也支持 Ctrl/Shift 多选和空格切换勾选。点击“删除”可批量删除勾选的零库存商品。删除采用停用方式，商品不再出现在库存及采购、销售选择中，历史单据和流水保留。有库存或已加入当前销售清单的商品不能删除；批量操作中任意商品不符合条件时，整批不删除并提示原因。

在“销售开单”可点击客户旁的“新增客户”，填写客户名称（必填）、电话和地址，点击“保存并选中”即可继续开单，当前商品清单及收款输入保留。

修改操作：

- 商品库存：只选择一个商品，点击“修改销售价”。新价格用于后续开单的默认单价，已经加入清单或已确认的销售明细保留原单价。
- 销售开单：确认出库前，选中清单行点击“修改选中”，或双击该行，可修改商品、数量和单价。保存时检查库存并重算小计、合计；客户、备注和本次收款仍可直接修改。
- 客户管理：选中客户点击“修改”，或双击客户行，可修改名称、电话和地址；客户编号及欠款关联保留。历史查询和重新打印时显示当前客户资料。

## 打印

点击打印时会在默认浏览器中打开 A4 横向 HTML 单据，按 Ctrl+P 选择打印机，并关闭浏览器页眉和页脚。可使用系统 PDF 打印机保存 PDF。

单据包含公司名、经营范围、公司地址、联系电话，以及留给客户手写的签名栏。每次生成打印预览使用当前已保存的公司资料，历史销售单重新打印也使用当前资料。

版式参照纸质批发清单：九列商品表格（序号、配件编码、名称、单位、数量、单价、金额、品牌、备注），按实际商品行数打印，合计含人民币大写。品牌和商品备注暂留空供手写；已收、未收及整单备注仍保留。示例见 `previews/print-preview.html`。

## 数据库与备份

数据库默认放在 `%LOCALAPPDATA%\AutoPartsMVP\autoparts.db`，按“备份数据库”生成安全一致的 .db 备份文件。建议每天营业结束备份到 U 盘或其他磁盘。数据只在本电脑。

## MVP 范围与限制

- 已包含：商品录入、客户录入、单品采购入库、多商品销售、库存不足校验、应收和后续收款、销售单打印、CSV 导出、手动数据库备份、库存流水数据库记录。
- 当前不包含：销售退货与冲销、采购退货、商品名称/单位等其他资料编辑、扫码枪、优惠折扣、赊账额度、多仓库、员工权限、多电脑同步、库存流水可视化、自动定时备份、正式财务会计/税务开票、含税价计算。
- 已确认单据不可直接编辑删除；发生差错需要通过后续版本的红冲/退货流程纠正（当前请先在测试数据中试用）。
- 销售数量目前为正整数；金额采用整数分存储，避免浮点误差。
- 本项目是个人/门店验证版，正式用于生产营业前请测试打印排版、备份恢复、断电情形及业务流程。

## 打包成 EXE（可选）

GitHub 构建：在仓库 Actions 中选择 Windows EXE 并运行。构建会执行测试、生成带图标的 Windows 64 位 EXE，并检查打包程序启动。成功后下载 `autoparts-windows-x64` 构建产物，解压并双击 EXE 即可使用，无需安装 Python。构建产物包含使用说明和 SHA256 校验文件，保留 30 天。

Windows 7 SP1：选择单独的 `Windows 7 EXE` 工作流，下载 `autoparts-windows7-x86`。该版本使用 Python 3.8.10、PyInstaller 5.13.2 生成 32 位程序，可用于 32 位和 64 位系统。GitHub 启动检查运行在较新 Windows 上，尚未在真实 Win7 验证。普通 Windows EXE 工作流使用 Python 3.12，不适用于 Win7。兼容版不需要用户安装 Python，数据位置保持一致。

本地 Windows 构建：

`py -m pip install pyinstaller`

`py scripts/build_windows.py`

生成的 `dist\汽配批发管理系统.exe` 可以放到 Windows 电脑运行，包含软件图标。注意用 Windows 系统构建 Windows EXE。图标资源位于 `assets/`，直接运行源代码时也需要保留此目录。
